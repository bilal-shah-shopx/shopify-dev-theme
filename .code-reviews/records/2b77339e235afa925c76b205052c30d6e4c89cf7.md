### Medium (1)

- **snippets/cart-drawer.liquid, sections/main-cart-items.liquid:158–168, sections/cart-notification-product.liquid:35–45** — `item.properties` (key and value) are rendered via `{{ property.first }}` / `{{ property.last }}` without `| escape`. Line item properties are merchant/buyer-controlled (injected via add-to-cart form `properties[]` inputs). Liquid does not auto-escape, so a crafted property value like `<img src=x onerror=…>` renders as raw HTML. Shopify sanitises properties server-side in most flows, but the theme layer should not rely solely on platform sanitisation. Add `| escape` to both `{{ property.first }}` and `{{ property.last }}` in all three files. The upload-file branch (`property.last contains '/uploads/'`) may pass through, but the displayed filename (`property.last | split: '/' | last`) also needs `| escape`. *(security)*
